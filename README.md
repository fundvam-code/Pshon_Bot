# Telegram-бот для 1С:Альфа авто

Бот работает напрямую с базой 1С:Альфа авто 5 (платформа 8.3) через COM. Своей базы данных у бота нет: всё, что вы видите и вводите в Telegram, читается из 1С и пишется в 1С.

## Что умеет
- **Справочники → Клиенты и машины:** поиск клиента (с его машинами и кнопкой «Добавить машину»), добавление клиента с подтверждением и сразу следом машины (итог «кому и какая машина» → подтверждение → запись в 1С), защита от дублей.
- **Справочники → «Добавить з/ч» и «Добавить название работы»:** сверка с 1С, при совпадении сообщение «запись существует», при похожих список с кнопками «Добавить»/«Отмена»; новые записи кладутся в папки «Запчасти для разнесения» и «Работы для разнесения», добавление пишется в `logs/added_works.log`.
- **Заказ-наряды → «Создать заказ-наряд»:** клиент (найти или создать) → машина (выбрать или создать) → итог → подтверждение → ЗН в состоянии «В работе» → «Добавить работы?» (на работы ставится исполнитель по умолчанию).
- **Заказ-наряды:** сколько ЗН не закрыто (ФИО, авто, стоимость работ); редактирование ЗН «В работе»: список работ, инфо (нормочасы и общая стоимость), добавление работы (поиск в справочнике, похожие, создание в группе «Работы для разнесения»), вывод и добавление запчастей клиента (вкладка «Материалы заказчика»).
- Кнопки находятся прямо под сообщениями; права пользователей задаются в `config/users.json`.

## Развёртывание на новом ПК (Windows 10/11)

### 0. Что нужно заранее
- Установленная **32-битная** платформа 1С:Предприятие 8.3 (по умолчанию `C:\Program Files (x86)\1cv8\<версия>`) и файловая база Альфа авто (каталог с `1Cv8.1CD`).
- Пользователь 1С с правом **«Внешнее соединение»** (в проекте — «Робот»). Без этого права подключение даст ошибку «Внешнее соединение не разрешено…». Право выдаётся в Конфигураторе: Администрирование → Пользователи → роль с правом «Внешнее соединение».
- Токен бота: в Telegram написать @BotFather → `/newbot` → скопировать токен.
- Доступ в интернет до Telegram.

### 1. Установить Git и uv
```bash
winget install Git.Git
winget install astral-sh.uv
```
Перезапустите терминал.

### 2. Скачать проект
```bash
git clone https://github.com/fundvam-code/Pshon_Bot.git C:\1C\Pshon_bot
cd C:\1C\Pshon_bot
```

### 3. Создать 32-битное окружение Python
Платформа 1С 32-битная, COM-коннектор доступен только 32-битному Python. Системный (64-битный) Python не подойдёт: будет ошибка «Класс не зарегистрирован».
```bash
uv venv --python cpython-3.12-windows-x86 .venv32
uv pip install --python .venv32\Scripts\python.exe -r requirements.txt
```
Проверка: `.venv32\Scripts\python.exe -c "import struct; print(struct.calcsize('P')*8)"` должна вывести `32`.

### 4. Проверить, что COM-коннектор 1С зарегистрирован
```bash
reg query HKCR\V83.COMConnector
```
Если ключа нет, зарегистрируйте библиотеку (терминал **от администратора**, подставьте свою версию платформы):
```bash
regsvr32 "C:\Program Files (x86)\1cv8\8.3.27.2170\bin\comcntr.dll"
```

### 5. Настроить
1. `copy .env.example .env` и заполнить `.env`. Это единственный файл, который нужно править под конкретный ПК: в коде нет ни путей, ни логинов.

   | Параметр | Что это |
   |---|---|
   | `TELEGRAM_TOKEN` | токен бота от @BotFather (обязательно) |
   | `ONE_C_DB_PATH` | каталог файловой базы 1С, где лежит `1Cv8.1CD` |
   | `ONE_C_SERVER`, `ONE_C_BASE` | вместо `ONE_C_DB_PATH`, если база серверная: сервер 1С и имя базы в кластере. Если `ONE_C_SERVER` задан, используется этот режим |
   | `ONE_C_USER`, `ONE_C_PASSWORD` | пользователь 1С с правом «Внешнее соединение» и пароль (может быть пустым) |
   | `ONE_C_PROGID` | COM-коннектор, по умолчанию `V83.COMConnector` (платформа 8.3); для 8.2 — `V82.COMConnector` |
   | `ONE_C_DEFAULT_EXECUTOR` | ФИО исполнителя по умолчанию для работ в ЗН, созданных через бота (сотрудник в 1С с признаком «Исполнитель») |
   | `ONE_C_CURRENCY` | необязательно: валюта учёта для новых записей |
   | `USERS_CONFIG` | необязательно: путь к `users.json` |

   Бот при запуске проверяет настройки и, если что-то не так (нет токена, неверный каталог, нет файла `1Cv8.1CD`), пишет, что исправить в `.env`.
2. `copy config\users.example.json config\users.json` и вписать реальные Telegram ID пользователей. Свой ID можно узнать у запущенного бота командой `/myid`, поэтому первый запуск допустим с любым содержимым файла.
3. Права в `users.json`: `view_clients`, `add_client`, `add_car` (раздел «Справочники»), `view_work` (раздел «Заказ-наряды»).

`.env` и `config/users.json` содержат личные данные и в репозиторий не попадают.

### 6. Проверить подключение к 1С
```bash
.venv32\Scripts\python.exe check_structure.py
```
Скрипт должен вывести список справочников и документов базы. Если выводится ошибка — смотрите раздел «Типовые ошибки».

### 7. Запустить
```bash
python run_bot.py
```
`run_bot.py` сам перезапускается в 32-битном окружении `.venv32`, поэтому запускать можно любым Python. Первое подключение к 1С занимает ~30 секунд, в логе появится «Бот запущен». Затем откройте бота в Telegram и отправьте `/start`.

### 8. Автозапуск при входе в Windows (по желанию)
```bash
schtasks /Create /TN "AlfaAutoBot" /SC ONLOGON /TR "\"C:\1C\Pshon_bot\.venv32\Scripts\pythonw.exe\" \"C:\1C\Pshon_bot\run_bot.py\""
```
Остановить: `schtasks /End /TN "AlfaAutoBot"`, удалить: `schtasks /Delete /TN "AlfaAutoBot" /F`. Задача запускается под тем же пользователем Windows, который работает с 1С.

## Эксплуатация
- **Логи:** `logs/bot.log` (работа бота и ошибки), `logs/added_works.log` (кто и какие работы добавил в справочник).
- **Обновление:** `git pull`, затем перезапуск бота. Зависимости при необходимости: `uv pip install --python .venv32\Scripts\python.exe -r requirements.txt`.
- **Один экземпляр:** с одним токеном может работать только один запущенный бот.
- **Резервная копия:** перед первым боевым запуском сделайте копию каталога базы 1С. Бот пишет в рабочую базу.
- **Новый пользователь:** добавьте его Telegram ID в `config/users.json` и перезапустите бота.

## Типовые ошибки
| Сообщение | Причина и решение |
|---|---|
| `Класс не зарегистрирован` | Запуск 64-битным Python или не зарегистрирован `comcntr.dll`. Используйте `.venv32` (шаг 3), выполните шаг 4. |
| `Неверно указан пользователь или пароль` | Проверьте `ONE_C_USER` / `ONE_C_PASSWORD` в `.env`. |
| `Внешнее соединение не разрешено для указанного пользователя` | Выдайте пользователю 1С право «Внешнее соединение». |
| `Информационная база не обнаружена` / «нет файла базы 1Cv8.1CD» | Неверный `ONE_C_DB_PATH`: нужен каталог, где лежит `1Cv8.1CD` (для серверной базы задайте `ONE_C_SERVER` и `ONE_C_BASE`). |
| `Ошибка настройки: …` при запуске | В `.env` не хватает параметра или он неверный, текст ошибки подскажет какой. |
| `Conflict: terminated by other getUpdates request` | Бот уже запущен в другом окне или на другом ПК с тем же токеном. Остановите лишний экземпляр. |
| `Failed building wheel` при установке | Используйте `uv` и 32-битное окружение (шаг 3): готовые пакеты собирать не нужно. |
| Бот долго не отвечает после запуска | Первое подключение к 1С занимает до ~30 секунд. |
| Бот отвечает «Вы не зарегистрированы» | Добавьте Telegram ID (`/myid`) в `config/users.json`, перезапустите бота. |

## Структура проекта
```
run_bot.py            запуск (сам переключается на 32-битный Python)
check_structure.py    проверка подключения, список справочников/документов 1С
src/bot.py            Telegram-бот: меню-кнопки, сценарии
src/one_c.py          работа с 1С через COM (поиск и запись)
src/access.py         пользователи и права
src/config.py         чтение и проверка настроек из .env
config/               users.example.json (шаблон), users.json (ваш, не в git)
.env.example          шаблон настроек
STRUCTURE.md          какие справочники, регистры и поля 1С использует бот
```
Описание каждой функции — в docstring'ах кода (`src/one_c.py`, `src/bot.py`).
