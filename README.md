# 🚗 Telegram бот для управления справочниками Альфа авто

Бот для управления справочниками клиентов и автомобилей в 1С:Альфа авто через Telegram.

## 📋 Возможности

- ✅ Просмотр и поиск клиентов
- ✅ Просмотр автомобилей клиентов (марка, модель, гос. номер, VIN, год)
- ✅ Добавление новых клиентов
- ✅ Добавление новых автомобилей
- ✅ Система управления правами доступа (роли: Администратор, Мастер)
- ✅ История операций и логирование
- ✅ Синхронизация с 1С базой

## 🔧 Установка

### Требования
- Python 3.8+
- Windows (для работы с COM подключением к 1С)
- 1С:Альфа авто 5 версии 8.3

### Шаги установки

1. **Клонируйте репозиторий:**
```bash
cd C:\1C\Pshon_bot
```

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
venv\Scripts\activate
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Скопируйте и заполните .env файл:**
```bash
copy config\.env.example .env
```

Отредактируйте `.env`:
```
TELEGRAM_TOKEN=YOUR_BOT_TOKEN
ONE_C_DB_PATH=C:\1C\Pshon
ONE_C_USER=username
ONE_C_PASSWORD=password
SQLITE_DB=bot_data.db
USERS_CONFIG=config/users.json
```

5. **Получите Telegram Bot Token:**
   - Напишите @BotFather в Telegram
   - Выполните `/newbot`
   - Скопируйте полученный токен в .env

6. **Настройте пользователей в `config/users.json`:**
```json
{
  "users": [
    {
      "telegram_id": 123456789,
      "name": "Андрей",
      "role": "admin",
      "permissions": [...]
    },
    {
      "telegram_id": 987654321,
      "name": "Мастер Петя",
      "role": "master",
      "permissions": [...]
    }
  ]
}
```

## 🚀 Запуск

### Запуск бота:
```bash
python src/bot.py
```

### Синхронизация с 1С:
```bash
python src/sync.py
```

   - 🔍 Найти клиента

## 🔗 Подключение к 1С

Бот использует COM объект для подключения к 1С:
- **Синхронизация:** автоматическая при запуске `sync.py`
- **Добавление данных:** данные добавляются в локальную SQLite БД
- **Обновление:** периодическая синхронизация

## 📊 База данных

SQLite база содержит таблицы:
- `clients` - клиенты
- `cars` - автомобили
- `sync_log` - логи синхронизации
- `audit_log` - история всех операций

## 🐛 Логирование

Логи сохраняются в:
- `logs/bot.log` - основной логи бота
- SQLite таблица `audit_log` - история операций
