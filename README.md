# Telegram-бот для 1С:Альфа авто

Бот работает напрямую с базой 1С:Альфа авто (8.3) через COM: ищет и добавляет клиентов и автомобили, показывает и редактирует заказ-наряды. Собственной БД у бота нет.

## Возможности
- Клиенты и машины: поиск, добавление клиента, добавление машины (марка/модель, госномер, VIN, год), защита от дублей.
- Заказ-наряды: список незакрытых ЗН (ФИО, авто, стоимость работ), редактирование ЗН «В работе»: список работ, инфо по ЗН (н/ч и общая стоимость), добавление работы (поиск в справочнике, похожие, создание в группе «Работы для разнесения»).
- Права пользователей в `config/users.json`.

## Установка (Windows)
Платформа 1С 32-битная, поэтому нужен **32-битный Python** (COM-коннектор 1С регистрируется только для 32 бит):

```bash
uv venv --python cpython-3.12-windows-x86 .venv32
uv pip install --python .venv32\Scripts\python.exe -r requirements.txt
```

1. Скопируйте `config/.env.example` в `.env` в корне проекта и заполните: `TELEGRAM_TOKEN`, `ONE_C_DB_PATH`, `ONE_C_USER`, `ONE_C_PASSWORD`.
2. Скопируйте `config/users.example.json` в `config/users.json` и впишите реальные Telegram ID (узнать: команда `/myid` у бота).
3. Пользователю 1С нужно право «Внешнее соединение».

## Запуск
```bash
python run_bot.py
```
`run_bot.py` сам перезапускается в `.venv32`. После старта бот ~30 секунд подключается к 1С.

`check_structure.py` выводит справочники и документы базы (проверка подключения).

## Важно
`.env` и `config/users.json` содержат личные данные и в репозиторий не попадают. Структура данных 1С описана в `STRUCTURE.md`.
